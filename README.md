# Rednote Formatter · 文案排版

免费在线文案排版工具 — 小红书 & 朋友圈 / Free online text formatter for Rednote (Xiaohongshu) & WeChat Moments.

**线上 / Live**: https://rednote-formatter.kuige.me/

## 功能 / Features

- **小红书模式 / Rednote mode**
  - emoji 分隔符 8 种预设 + 自定义（· · · / 🌿 / ✨ / ⋆˚✿˚⋆ …）
  - 长句智能分行：大段自动拆成短行，密度与行距可调
  - emoji 点缀：自动替换列表符号（🔹 自然 / 混搭活泼）
  - 标题美化：【】/ 🔥 / ✨ 多种样式
  - 话题标签生成器：中英双标签库（15 品类 × 大流量/品类/长尾组合）
  - 实时字数统计：标题 20 字 / 正文 1000 字超限提醒
- **朋友圈模式 / Moments mode**
  - 全角空格居中排版（窄/标准/宽三档屏宽校准）
  - 顶部留白防折叠（0–8 行）
  - 首行重点：字距拉开
- **通用 / Common**
  - 手机框实时预览、一键复制（全部/仅正文）、⌘/Ctrl+Enter 快捷键
  - 中英双语界面（`?lang=` 深链 + hreflang）、亮暗主题、草稿自动保存
  - **100% 浏览器本地处理**，无后端、无统计上传、文案绝不上传

## 技术栈 / Stack

单文件 `index.html`（内联 CSS/JS，零依赖零构建）→ GitHub Pages 静态部署。

## 隐私 / Privacy

所有排版计算均在你的浏览器内完成，工具不收集任何数据。
